
Overview

Insurance underwriting often involves collecting information from multiple documents, validating submissions, reviewing historical data, analysing financial stability, identifying operational risks, and finally preparing a recommendation for the underwriter. Performing these activities manually is time-consuming and often requires switching between several systems before a decision can be made.

InsureIQ is an AI-powered underwriting platform built using UiPath Agents, UiPath Coded Agents, LangGraph, Python, and UiPath Orchestrator to automate this workflow.

Instead of relying on a single AI model to perform every task, InsureIQ distributes the workload among specialised agents, each responsible for a specific stage of underwriting. These agents collaborate through UiPath Case Management and Storage Buckets, allowing multiple risk assessments to run simultaneously before generating a consolidated underwriting report.

The solution demonstrates how AI agents and robotic automation can work together while ensuring that the final underwriting decision remains with the human underwriter.

How InsureIQ Works

Every underwriting request follows a structured workflow consisting of three major stages.

Stage 1 — Ingestion

The workflow begins when a new underwriting submission arrives through Microsoft Outlook.

This stage is handled by the Audit Agent, which acts as the entry point for every case.

Rather than immediately performing risk analysis, the Audit Agent first ensures that the submission is complete and suitable for processing.

During this stage the agent:

Reads the incoming email
Extracts all attachments
Parses PDF, Word, Excel and image documents
Extracts business information
Identifies the insurance line of business
Detects missing or incomplete information
Validates mandatory fields
Converts the submission into a structured JSON format

Once validation is complete, both the original documents and the extracted JSON are stored in a UiPath Storage Bucket, making them available to the remaining agents without requiring duplicate processing.

Stage 2 — Research

After the Audit Agent finishes its work, the underwriting case moves to the Research Stage.

Unlike the previous stage, this phase is designed for parallel execution.

Three specialised AI agents begin working simultaneously on the same underwriting case.

Since each agent analyses a different aspect of risk, they operate independently while sharing the structured case data stored in the Storage Bucket.

Running these agents in parallel significantly reduces overall processing time.

Claim History Agent

The Claim History Agent analyses historical insurance claims associated with the customer.

It evaluates:

Previous claims
Claim frequency
Claim severity
Historical loss patterns
Repeat incidents

The result is a Claim Risk Score together with observations explaining why the applicant represents a particular level of risk.

Financial Risk Agent

The Financial Risk Agent is implemented as a UiPath Coded Agent using Python and LangGraph.

It evaluates the financial health of the insured organisation by analysing financial information and publicly available business data.

The agent examines:

Financial statements
Revenue trends
Liquidity
Profitability
Debt obligations
Cash flow
Corporate financial stability

The outcome is an explainable Financial Risk Score along with supporting observations.

Operational Risk Agent

The Operational Risk Agent focuses on operational exposure that could affect the insured asset.

For marine underwriting it analyses:

Shipping routes
Maritime operational conditions
Weather conditions
News related to shipping
High-risk regions
Route disruptions

The agent combines these factors to produce an Operational Risk Score together with operational recommendations.

Stage 3 — Review

The Review Stage begins only after all three research agents have completed successfully.

The Summary Agent gathers the outputs generated by every risk assessment agent and prepares a consolidated underwriting report.

Instead of performing new analysis, this agent combines the results into a single decision-support document that includes:

Executive Summary
Financial Assessment
Claim History Assessment
Operational Assessment
Individual Risk Scores
Overall Risk Score
Risk Category
Key Findings
Recommendations

After the report has been generated, a RiskReportForm allows the underwriter to review the assessment before any business decision is made.

Once the review is complete, a CleaningRPA process archives temporary artefacts, updates the case status and performs housekeeping activities to prepare the system for future submissions.

Architecture Highlights

Some of the key architectural characteristics include:

Event-driven workflow initiated by Microsoft Outlook
Sequential ingestion and validation process
Parallel execution of specialised research agents
Shared case data using UiPath Storage Buckets
UiPath Case Management for orchestration
Human review before final underwriting
Automated cleanup after case completion

Business Value

By combining document processing, AI agents, robotic automation and parallel risk analysis into a single workflow, InsureIQ helps reduce manual underwriting effort while improving consistency and transparency.

Instead of spending hours gathering information from different systems, underwriters receive a structured report containing validated submission details, claim history insights, financial analysis and operational intelligence in one place. This enables faster turnaround times, more consistent risk assessments and allows underwriters to focus on informed decision-making rather than repetitive investigative work.
